# Welcome to ManualPress 🚀

**ManualPress**는 마크다운(Markdown)으로 작성된 문서를 별도의 복잡한 구축 과정 없이 빠르고 아름다운 웹사이트로 변환해 주는 문서 퍼블리싱 서비스입니다.

## ✨ Key Features

- **Markdown-First:** 익숙한 마크다운 문법 그대로 완벽한 기술 문서 및 매뉴얼 사이트 구축
- **Fast & Lightweight:** 불필요한 거품을 걷어내고 문서 가독성에만 집중한 초고속 렌더링
- **Seamless Integration:** GitHub 저장소와 연동하여 커밋과 동시에 자동으로 배포되는 매끄러운 워크플로우

## 🛠️ Organizations & Repositories

이 조직(`.github`)은 ManualPress 서비스 전반의 공통 정책, 템플릿, 그리고 마크다운 문서 저장소들을 총괄합니다. 각 프로젝트별 상세 매뉴얼과 가이드는 개별 저장소를 참고해 주세요.
